# 简历工坊 ResumeForge

写简历的时候，最要命的不是排版，是**你根本不知道哪句话会被筛掉**。

这个工具就干一件事：你左边写，右边实时体检，每条要点、每个关键词、每段时长都给你摊开算清楚。

**纯本地运行**——没有后端、没有账号、不上传任何数据，你的简历只存在于你自己浏览器的 localStorage 里。断网也能用。

## 它检查什么

七项加权评分，分数线 100：

| 维度 | 权重 | 在查什么 |
|---|---|---|
| 成果量化 | 30% | 你的要点里有没有数字。全是「负责 XX」而没有结果，等于没写 |
| 动词强度 | 15% | 弱动词识别：「负责/参与/协助/配合」占比过高就是在写岗位说明书 |
| 结构完整 | 18% | 七个板块齐不齐（基本信息/简介/技能/经历/项目/教育/联系方式） |
| 时间线健康 | 10% | 空档、倒序错乱、单段经历不足 6 个月 |
| 岗位聚焦 | 12% | 内容跟你写的目标岗位对不对得上（内置 8 类岗位词库） |
| 空话控制 | 10% | 「性格开朗」「沟通能力强」「团队合作精神」这类零信息量表达 |
| 联系可达 | 5% | 手机、邮箱格式是否真的能被 HR 点通 |

评分为 A/B+/B/C/D 五档，每条扣分都给出**具体到某一条要点的改法**，而不是笼统说"建议优化"。

## JD 匹配

把目标岗位的 JD 贴进去，它抽出关键词，逐个比对你的简历，直接告诉你：

- 哪些词 JD 有、你简历里也有（命中）
- 哪些词 JD 有、你简历里没有（**最可能被筛掉的原因**）
- 处理原则只有一条：你会但没写 → 补进去；你不会 → 别编，去补真实经历

关键词抽取做了中文去噪（过滤「岗位要求」「年以上」「开发经验」这类无意义片段）和重复合并（`Node.js` 与 `node`、`vuejs` 与 `vue` 不会重复计数）。

## 用起来

浏览器直接打开 `index.html`，或者在线版：**https://langlangbody.github.io/resume-forge/**

- 四个版式模板（经典 / 现代 / 紧凑 / 衬线）
- 字号缩放 80%–120%
- 「导出 PDF」：A4 单页排版，打印即成品
- 「存稿 / 读取」：导出或导入 JSON，草稿自动存浏览器

## 跑测试

```bash
node test/engine.test.js
```

45 条断言，覆盖评分逻辑、日期解析、岗位识别、JD 匹配、空输入与边界输入。纯 Node 运行，无浏览器依赖。

## 结构

```
index.html                三栏布局：编辑 / A4 预览 / 体检报告
assets/engine.js          评分引擎（纯逻辑，UMD，可在浏览器和 Node 里跑）
assets/app.js             状态 + 渲染，无框架
assets/styles.css         全部 --rf-* 变量；含 @media print 打印样式
test/engine.test.js       45 条断言
```

引擎和界面是分开的：`engine.js` 不碰 DOM，所有评分逻辑都能在 Node 里直接调用，所以它可被测试、可被复用、可以被别的界面接走。

## 为什么做这个

简历代写是需求密度最高、单价最低、交付最纯文本的赛道——但它解决的问题是"帮你写"，而 2024 年之后真正的痛点是**"AI 批量生成的简历全都在同质化，HR 一眼看穿"**。

所以这里不生成任何内容。它只做一件事：告诉你哪里会被筛掉。写得怎么样是你的事，能不能过筛是它的事。
